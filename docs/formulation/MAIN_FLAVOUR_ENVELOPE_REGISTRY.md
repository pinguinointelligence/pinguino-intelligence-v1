# Main Flavour Envelope Registry

The sole runtime authority is `product_behavior_policy_versions`. The former
TypeScript flavour-floor registry has been removed from runtime resolution.
Manufacturer dosage references that prove only a floor, but not an OPTIMAL
ceiling and hard limit, remain review evidence and cannot authorize automatic
reduction until a complete server policy is published.

The minimum-only Hazelnut `PI-ING-000431` and Coffee `PI-ING-000245`
references are therefore not published runtime envelopes. They remain exact
review evidence and freeze the selected Main baseline until an approved upper
bound and hard limit exist.

The Vegan and Protein ceilings above are conservative exact-identity maxima
proven across the accepted −11/−12/−13 fixtures and target/route sweeps; they
are not family-wide sensory claims. Vegan Strawberry/Banana share only the
explicit 82.5% combination envelope. Protein Strawberry/Banana share only the
explicit 20.7% combination envelope. Sweetened/diluted nut compounds still
require an exact reviewed equivalent factor. Unknown coffee retained mass,
unknown alcohol ABV and uncalibrated chocolate/compound forms block only their
automatic Main policy; Standard eligibility remains an independent resolver
decision. No percentages are copied between profiles.

New reviewed taxonomy/policy rows can classify a future product server-side without a frontend deployment. Unknown rows create consolidated review cases.
