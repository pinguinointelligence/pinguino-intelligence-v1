# Label workflow — Owner Decision 2026-09-06

This document records the implemented Label workstream. It is additive: the numbering and status of `SOL-001` through `SOL-034` are unchanged.

## Missing-field inventory

`unknown` never means zero, “none”, or a user-confirmed guess. A field blocks print only when the selected market/purpose requires it or when a shared print/preflight rule says so.
